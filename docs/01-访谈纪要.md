# 01 - 访谈纪要（P1 发散访谈）

- 日期：2026-08-14
- 方式：P0 对齐 + 3 轮 grilling 访谈 + 数据集选型
- 状态：✅ 已敲定，可进入需求定义

## 一、P0 对齐结论

| 项 | 结论 |
|---|---|
| 做什么（一句话） | 一个「健身自律工具」网页应用：输入个人情况 → 自动生成训练计划和每日食谱，配合每日打卡与数据统计，帮助你坚持自律 |
| 给谁用 | 学生和普通上班族（第一版单用户，自己用） |
| 最想要的价值 | 不是单纯记录，而是「帮我」：根据我的情况直接告诉我该练什么、吃什么、怎么做 |
| 产品形态 | 简单网页版（浏览器打开即用），移动优先（手机上好用），数据存本机 |
| 范围 | 第一版只做健身模块；学习、生活模块明确暂停 |

## 二、P1 第 1 轮问答

| # | 问题 | 决策 |
|---|---|---|
| Q1 | 健身档案采集哪些信息 | 全部采集：身高、体重、年龄、性别、目标（减脂/增肌/保持）、每周可训练天数、训练条件（健身房/徒手/哑铃）、饮食忌口、做饭条件（会不会做/时间）。一次性填写，之后每周只改体重 |
| Q2 | 食谱如何生成 | 目标 → 热量 → 从内置菜谱库按口味/忌口/厨艺难度筛选 → 自动排出早/午/晚+加餐每日菜单；**计量单位用「个/颗/份」，不用克**；做菜教学用文字分步骤 + 食材用量，不做视频 |
| Q3 | 训练计划怎么来 | 按目标+训练条件+每周天数从模板库匹配，生成后可手动调整 |
| Q4 | 学习模块 | **暂停**，第一版不做 |
| Q5 | 生活模块 | **暂停**，第一版不做 |
| Q7 | 数据统计 | 全部要：连续打卡天数、月度日历、习惯完成率、体重曲线 |
| Q8 | 自定义程度 | 全部可手动编辑、生成时有选择、可自定义 |

## 三、P1 第 2 轮问答（全部按推荐执行）

| # | 问题 | 决策 |
|---|---|---|
| Q1 | 每天打卡什么 | ① 今日训练完成打卡 ② 三餐饮食打卡（吃了/没吃/替换）③ 体重记录（可选） |
| Q2 | 训练记录深度 | 第一版只勾「完成」+ 可选备注，不做动作级重量/组数记录 |
| Q3 | 体重录入 | 手动输入，曲线按时间展示，不强求每天 |
| Q4 | 首页布局 | 「今日卡片」：今日该练什么 + 今日菜单（早/午/晚）+ 打卡按钮；顶部显示连续坚持天数 |
| Q5 | 菜单替换粒度 | 每餐默认 1 道 + 3 个候选替换菜，一键替换 |
| Q6 | 菜谱库规模 | 早/午/晚/加餐 4 类，每类 6~10 道，共约 30 道；按忌口和厨艺难度筛选 |
| Q7 | 数据备份 | 设置页提供 JSON 导出/导入 |
| Q8 | 热量算法 | 内置简化公式自动计算每日热量目标 + 设置里可手动覆盖 |

## 四、P1 第 3 轮问答（全部按推荐执行）

| # | 问题 | 决策 |
|---|---|---|
| Q1 | 训练计划模板 | 按「目标 × 训练条件 × 每周天数」匹配；每天展示：训练主题（如胸+三头）+ 动作列表（动作名、组数、次数、休息时间、一句话动作说明）；可手动增删改 |
| Q2 | 首次引导 | 首次进入先填健身档案，填完才进首页；之后可随时在设置修改 |
| Q3 | 补卡规则 | **不能补卡**，当天有效，错过即断连续天数 |
| Q4 | 历史查看 | 日历点某一天可回看当天训练与饮食 |
| Q5 | 多档案 | 第一版单用户 |
| Q6 | 浏览器通知 | 设置里提供开关，默认关闭 |
| Q7 | 视觉风格 | 移动优先卡片式布局，浅色为主 + 绿色点缀，大按钮方便手机点按 |

## 五、数据集选型（用户指定：GitHub exercise dataset）

- 选定：**[hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)**（MIT，1,324 个动作）

## 六、已敲定的关键决策汇总

1. 产品 = 健身自律助手（训练计划 + 每日食谱 + 打卡 + 统计）
2. 移动优先的纯前端 Web 应用，数据存本机（localStorage/IndexedDB），支持 JSON 导出/导入
3. 生成逻辑全部为「规则/模板驱动 + 用户可手动覆盖」，不做复杂算法
4. 打卡不可补，自律优先
5. 训练动作库使用开源数据集（中文教程），菜谱库由我们内置约 30 道
