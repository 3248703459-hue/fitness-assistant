# 健身助手 (Fitness Assistant)

A mobile-first self-discipline assistant for fitness, diet and daily check-ins.
100% client-side: no server, no account. All data stays in the browser (localStorage)
with JSON export/import backup. Ships as an installable PWA that works offline.

## Features
- Onboarding: height / weight / age / gender, goal, training days, equipment (gym / dumbbells / bodyweight), food avoidances, cooking skill
- Today: today's workout + check-in, today's meal plan + check-in, body weight log
- Plan: weekly training plan auto-generated by goal; edit sets / reps / rest, add or remove exercises, regenerate the week
- Exercise library: all 1,324 exercises from the open Exercise Dataset, with Chinese names, step-by-step Chinese instructions and animated GIFs
- Diet: daily 4-meal menu matched to calorie target and avoidances, with replaceable alternatives; ingredient amounts in natural units (piece / clove / bowl), step-by-step cooking text
- Stats: streak days, weekly completion rate, monthly calendar, weight chart, day review
- Settings: edit profile, calorie target, export / import data

## Run locally
Open `outputs/app/index.html` directly, or serve it:
```
python -m http.server 8080 --directory outputs/app
```
Then visit http://localhost:8080 (needed for PWA / service worker testing).

## Tests
```
node --test tests/logic.test.mjs
```

## Deploy to GitHub Pages
1. Create an empty public repo on GitHub, e.g. `fitness-assistant`.
2. Push this repo to it:
```
git remote add origin https://github.com/<your-name>/fitness-assistant.git
git branch -M main
git push -u origin main
```
3. In repo Settings -> Pages, set Source to "GitHub Actions" (the included workflow publishes `outputs/app` automatically on every push).
4. Open https://<your-name>.github.io/fitness-assistant/

## Layout
- `app/` - application source (kept in sync with `outputs/app`)
- `outputs/app/` - deployable site root
- `docs/` - interview notes, requirements, PRD, design spec
- `tests/` - unit tests
